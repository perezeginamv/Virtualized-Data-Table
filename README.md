# Virtualized Data Table

Тестовое задание: виртуализированная таблица данных.

🔗 Ссылки
- Развернутое приложение: https://perezeginamv.github.io/Virtualized-Data-Table/

🚀 Стек

- Vite — современнейший сборщик и инструмент для разработки, обеспечивающий быстрый запуск и горячую перезагрузку;
- React 19
- TypeScript
- @tanstack/react-table
- @tanstack/react-virtual

▶️ Запуск

- git clone https://github.com/perezeginamv/Virtualized-Data-Table.git
- cd Virtualized-Data-Table
- npm install
- npm run dev

📦 Сборка

npm run build

## Что реализовано в проекте

- 100 000 строк
- вертикальная виртуализация
- overscan
- корректная нумерация строк 1–100 000
- сохранение выбранной строки при скролле
