Тестовое задание: виртуализированная таблица данных.

- cd Virtualized-Data-Table
- npm install
- npm run dev

📦 Сборка

npm run build

## Что реализовано в проекте

- 100 000 строк данных, загружаемых в память целиком;
- вертикальная виртуализация с помощью @tanstack/react-virtual;
- в DOM находятся только видимые строки + небольшой overscan;
- scrollbar соответствует всему массиву из 100 000 строк;
- корректная нумерация строк от 1 до 100 000;
- выделение строки по клику;
- сохранение выделения при прокрутке;
- сохранение выделения после перемешивания;
- кнопка «Перемешать»;
- случайное перемешивание массива с использованием алгоритма Fisher–Yates;
- сохранение идентичности строк после перемешивания;
- виртуализация продолжает работать после любого количества перемешиваний.

🔢 Нумерация строк

Для стабильной нумерации в DataRow используется дополнительное поле rowNumber:

interface DataRow {
    id: number;
    rowNumber: number;
    text: string;
}

После shuffle `rowNumber` остаётся идентификатором конкретной строки, а `virtualRow.index` используется только для определения её текущей позиции в массиве физического положения в виртуализированном списке.

⚠️ Уточнение по требованиям к колонке #

В задании одновременно указано, что:

- номер является неизменной характеристикой конкретной строки;
- номер должен совпадать с текущей позицией строки в массиве.

После перемешивания эти условия могут противоречить друг другу.

В реализации приоритет отдан требованию о стабильном номере конкретной строки: если строка №7 после `shuffle` переместилась на другую позицию, она продолжает отображать `7`.

При этом текущая позиция строки определяется отдельно виртуализатором и соответствует её фактическому положению в массиве.

Такое разделение позволяет сохранить идентичность данных и корректное выделение строки после любого количества перемешиваний.
